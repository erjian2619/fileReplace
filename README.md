# FileReplaceTool

轻量文件替换工具，用于在 Windows 环境中快速把源文件或整个目录内容同步到目标目录，并在冲突时保持安全处理。

## 功能概览

- 文件模式：支持单个或多个文件替换，覆盖同名文件并保留其他内容
- 目录模式：支持整个目录替换，并可设置新目录名
- 自动保留旧目录：若目标位置已有同名目录，会改名备份并保留原内容
- 支持拖拽与手动选择：可直接拖入文件或目录，或使用浏览器选择
- 保存目标目录：支持记录最近使用的目标路径，便于后续操作

## 运行方式

1. 双击生成的 `FileReplaceTool.exe` 启动工具。
2. 选择“文件替换”或“整个目录替换”模式。
3. 设定源路径和目标目录。
4. 点击“检查并开始替换”执行操作。

## 编译方式

在 Windows 环境中执行：

```bat
build.bat
```

脚本会使用系统自带的 C# 编译器生成可执行文件：

```text
FileReplaceTool.exe
```

## 适用场景

- 批量更新项目中的资源文件
- 替换游戏目录中指定文件
- 复制整套目录并保留原目录历史
- 快速处理文件与目录同步需求

> 使用前请确认目标目录和替换内容，避免误替换关键文件。
